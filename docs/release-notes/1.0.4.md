# PocketDJ 1.0.4 — App Store release notes

Submitted 2026-11-06. The headline is Siri (merged da298898). The App Store build uses the
release Xcode 27.2, so Siri works through the phrases below, the Shortcuts app and Spotlight. The
natural-language **Siri AI** tools are compiled only into internal-TestFlight builds made with the
Xcode 27.3 beta. Apple's developer preview doesn't run them in App Store or external-TestFlight
builds, so these notes don't promise Siri AI.

Also in this release, merged after the 1.0.3 builds: d1ab06e0 (Now Playing Mix panel status UI).
The headerless-mp3 growing-file fixes (76dc87ed, b4d679e9) were already in the 1.0.3 builds:
ec94fcd6 contains them. They are deliberately left out of these notes.

Plain text only: App Store Connect rejects "♥" in whatsNew.

## iOS / iPadOS

```text
NEW: SIRI
Ask Siri to add songs to your pockets and playlists by name, with no tapping:
• "Add this song to Workout in PocketDJ" adds what's playing
• "Add a song to Workout in PocketDJ" lets you say any song, like "Make Me Proud by Drake"
• Siri tells you when a song is already there, and asks which one when two songs share a name

Control the mix by voice:
• "Turn on Mix Mode in PocketDJ" (or off)
• "Mute the vocals in PocketDJ", or "Unmute the drums": vocals, drums, bass or other. Muting turns on Mix Mode for you.

Also: "Play" or "Shuffle" any pocket or playlist by name. Everything is in the Shortcuts app too.

NOW PLAYING
• The Mix Mode status is centered and never cut off on iPhone
• FX Lock no longer adds a status line; its lock icon shows the state
```

tvOS has no Mix Mode, no Shortcuts app and no Siri AI tools. The App Shortcuts compile there, but
Apple TV's Siri hasn't been verified to run third-party App Shortcuts, so these notes claim nothing new:
