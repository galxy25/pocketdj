# PocketDJ — native (iPhone · iPad · Mac)

A **fully native SwiftUI** reimplementation of the PocketDJ client. It is
client-only and talks to the **same backends** as the web PWA:

| Concern            | Endpoint                                              |
|--------------------|-------------------------------------------------------|
| Catalog + cover art| CloudFront `https://djictbz9w796r.cloudfront.net` (dev) |
| Durable rips       | Public S3 `pocketdj-rips-011183829623` (`/rips/…`)    |
| Rip-on-demand + HLS| iMac rip server over Tailscale (`levis-imac.tail2e2bdf.ts.net`) |

All endpoints live in `PocketDJ/Support/Config.swift`. User collections
(pockets / playlists / setlists) are the only client-side state and will live
on-device.

## Project layout

The Xcode project is **generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)**
from `project.yml` — a single multiplatform app target (iPhone + iPad + Mac).

```
apple/
  project.yml                 # XcodeGen spec → PocketDJ.xcodeproj
  PocketDJ/
    PocketDJApp.swift         # @main App
    Support/                  # Config, Theme, Format, Camelot
    Models/IndexModels.swift  # Codable for current-index.json
    Services/CatalogService.swift
    State/AppModel.swift
    Views/                    # RootView, BrowseView, AlbumDetailView, CoverImage
    Assets.xcassets
```

## Build / regenerate

```bash
cd apple
xcodegen generate            # (re)create PocketDJ.xcodeproj from project.yml
open PocketDJ.xcodeproj       # then build/run for My Mac / an iPhone / an iPad
```

> Files are added on disk and the project is regenerated — don't add files via
> Xcode's UI (they'd be dropped on the next `xcodegen generate`).

### Command line

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
# Mac
xcodebuild -project PocketDJ.xcodeproj -scheme PocketDJ -destination 'platform=macOS' build
# iPhone / iPad simulators
xcodebuild -project PocketDJ.xcodeproj -scheme PocketDJ -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```
