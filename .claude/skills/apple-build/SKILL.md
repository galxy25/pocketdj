# Build the native PocketDJ apps (Apple platforms)

The native apps live in **`apple/`** — one multiplatform SwiftUI target
(`PocketDJ`) that runs on **iPhone, iPad, and Mac**. The Xcode project is
**generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)** from
`apple/project.yml`; edit files on disk and regenerate (don't add files via the
Xcode UI — they're dropped on the next generate).

## Prerequisites

```bash
# Full Xcode (not just Command Line Tools). xcode-select may still point at CLT,
# so set DEVELOPER_DIR per shell instead of needing sudo xcode-select:
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -version            # expect Xcode 26.x
which xcodegen || brew install xcodegen
```

## Generate the project

```bash
cd apple
xcodegen generate              # (re)creates PocketDJ.xcodeproj from project.yml
```

## Build for a simulator (iPhone / iPad)

The simulator needs no signing — override it off so a code-sign cert is never required:

```bash
xcodebuild -project PocketDJ.xcodeproj -scheme PocketDJ \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build -configuration Debug build \
  CODE_SIGNING_ALLOWED=NO
# product: build/Build/Products/Debug-iphonesimulator/PocketDJ.app
```

Install + launch on a booted sim with `simctl` (see the **apple-test** /
**run** flow):

```bash
UDID=$(xcrun simctl list devices booted | grep -m1 'iPhone 17 Pro' | grep -oE '[0-9A-F-]{36}')
xcrun simctl install "$UDID" build/Build/Products/Debug-iphonesimulator/PocketDJ.app
xcrun simctl launch "$UDID" com.levi.pocketdj
xcrun simctl io "$UDID" screenshot /tmp/pdj.png     # screenshots need no extra perms
```

## Build + run the Mac app

```bash
xcodebuild -project PocketDJ.xcodeproj -scheme PocketDJ -destination 'platform=macOS' \
  -derivedDataPath build-mac -configuration Debug build CODE_SIGNING_ALLOWED=NO
APP="$PWD/build-mac/Build/Products/Debug/PocketDJ.app"
codesign --force --deep --sign - "$APP"             # ad-hoc so Gatekeeper allows launch
xattr -dr com.apple.quarantine "$APP" 2>/dev/null
open "$APP"
```

## Signing

`project.yml` uses **automatic signing** with team **EC27UF79GL** (Levi Schoen) —
correct for **Xcode GUI builds**, device builds, and App Store archives.

From the **CLI**, `codesign` often can't reach the signing key headlessly
(`errSecInternalComponent`), so for scripted builds/tests:

- **Simulators** → pass `CODE_SIGNING_ALLOWED=NO` (no signing needed).
- **macOS** → build unsigned then **ad-hoc** sign (`codesign --sign -`), as above,
  or run via `apple/scripts/test-macos.sh`.

To make the real cert usable from the CLI (so `xcodebuild ... -allowProvisioningUpdates`
works for macOS/devices): open Keychain Access ▸ the **Apple Development** private
key ▸ Get Info ▸ Access Control ▸ **Allow all applications**. The cert itself is
created the first time you build in Xcode.app with a team selected.
